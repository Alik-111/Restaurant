# Maison Aurél

A responsive restaurant homepage built with Next.js, React, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Next.js. Use `npm run build` to create a production build.

## Project notes

- Restaurant photos are loaded from Unsplash and the preview video is hosted by Pexels.
- The reservation link is a mailto placeholder; update it with the restaurant's booking service before publishing.
- Replace the sample restaurant address, hours, menu, and social link with the real details.
